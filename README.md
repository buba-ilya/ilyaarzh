# Портфолио — шаблон сайта

Статический сайт-портфолио на Astro. Все фото и видео сейчас — **белые заглушки с надписью SOON**
в нужных пропорциях. Чтобы поставить свою работу, достаточно положить файл или вставить ссылку
в данные проекта: вёрстку трогать не нужно.

---

## 1. Установка и запуск

Нужен Node.js 22.12 или новее.

```bash
npm i
```

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер на http://localhost:4321 |
| `npm run build` | Продакшен-сборка в папку `dist` |
| `npm run preview` | Локальный просмотр собранного сайта |
| `npm test` | Юнит-тесты парсера ссылок на видео |
| `npm run check` | Проверка типов (`astro check`) |
| `npm run format` | Форматирование Prettier |
| `npm run og` | Пересобрать `public/og-default.jpg` |

## 2. Как заменить заглушки на свои работы

Есть два способа положить файл.

**Способ A — `src/assets` (рекомендуется).** Astro сам пережмёт картинку, сделает WebP
и несколько размеров под разные экраны. Путь пишется относительно `src/assets`:

```
src/assets/projects/project-01/thumb.jpg  →  thumbnail: 'projects/project-01/thumb.jpg'
```

**Способ B — `public/media`.** Файл отдаётся как есть, без обработки. Путь пишется от корня сайта:

```
public/media/project-01/thumb.jpg  →  thumbnail: '/media/project-01/thumb.jpg'
```

### Превью проекта (плитка на главной)

Поле `thumbnail`. Пропорции **16:9**, рекомендуемый размер **1920×1080**.

**Если оставить `thumbnail: ''`, превью подтянется из ссылки на видео автоматически** — берётся
кадр-обложка ролика:

- YouTube — напрямую по адресу `i.ytimg.com`, без запросов;
- Vimeo — один запрос к их oEmbed во время сборки, максимум 1280px по ширине.

Так что заполнять `thumbnail` нужно, только когда хочется **свой** кадр вместо обложки ролика.
Своё превью всегда перебивает автоматическое.

Обложка кропается под 16:9 по центру (`object-fit: cover`), поэтому у вертикальных или
квадратных кадров срежется верх и низ — в таком случае лучше положить свой файл.

Если ссылки на видео нет и `thumbnail` пустой — на плитке остаётся заглушка SOON.

### Кадры из проекта

Массив `stills`. **Кадры показываются в своих исходных пропорциях и никогда не кропаются** —
можно класть 16:9, 4:3, вертикальные, какие угодно. По ширине рекомендуется от 1920px,
дальше Astro сам нарежет размеры под разные экраны.

Если кадры разных пропорций, ряд в сетке выровняется по верхнему краю, а высота у плиток
будет разной — это нормально. Хочешь ровную сетку — клади кадры одного соотношения.

Пустая строка `''` в массиве — это заглушка SOON, так что можно заполнять постепенно:

```yaml
stills:
  - 'projects/quchbi-bag/still-1.jpg'
  - 'projects/quchbi-bag/still-2.jpg'
  - ''
  - ''
  - ''
  - ''
```

Файлы при этом лежат в `src/assets/projects/quchbi-bag/`.

Кадров может быть любое количество — сетка подстроится. Если массив пустой (`stills: []`),
блок кадров и лайтбокс вообще не выводятся: так сделано у `showreel`.

### Видео

В `videos[].url` вставляется ссылка на Kinescope, Vimeo или YouTube — тип плеера определяется
автоматически. Поддерживаются:

```
kinescope.io/5R3xLEV8QHLkcs4ev7hKPK        (страница видео)
kinescope.io/embed/5R3xLEV8QHLkcs4ev7hKPK  (ссылка для встраивания)
vimeo.com/123456789
vimeo.com/123456789/abcdef                 (приватное видео с хешом)
player.vimeo.com/video/123456789
youtube.com/watch?v=ID
youtu.be/ID
youtube.com/shorts/ID
youtube.com/embed/ID
```

**Kinescope.** Годится и адрес из строки браузера, и ссылка для встраивания — лишние параметры
вроде `?t=30` отбрасываются. Встраивается как `kinescope.io/embed/<ID>` с `autoplay=1` и `dnt=1`
(последний отключает трекинг), для шоурила добавляется `loop=1`.

### Пропорции плеера

По умолчанию блок видео — 16:9. Если ролик другого формата, задайте `ratio` у видео:

```yaml
videos:
  - url: 'https://kinescope.io/5R3xLEV8QHLkcs4ev7hKPK'
    ratio: '100/70.56'
```

Откуда взять число для Kinescope: в их панели нажмите «Поделиться» → код для вставки. Там будет
`<div style="position: relative; padding-top: 70.56%; ...">` — возьмите процент из `padding-top`
и напишите `100/<процент>`. Для 70.56% это `100/70.56`, то есть 1.417.

Без `ratio` ролик не 16:9 покажется с чёрными полосами сверху и снизу. Писать можно в любом
виде, который понимает CSS: `16/9`, `4/3`, `2.39`.

Важно: ссылка на Vimeo должна содержать **числовой ID**. Ссылка вида `vimeo.com/username`
не подойдёт — при сборке будет предупреждение в консоли, а на месте видео останется заглушка.

Обложка под кнопкой Play берётся так:

1. если задан `cover` — берётся он;
2. иначе подставляется кадр-обложка самого ролика — **только для YouTube и Vimeo**;
3. иначе блок остаётся чёрным: ролик на месте, просто без обложки.

Белая заглушка SOON появляется, только когда у видео вообще нет ссылки — то есть когда нет
самого фильма, а не его обложки.

У Kinescope обложка при сборке не запрашивается, поэтому для таких видео задавайте `cover`
вручную — удобно поставить один из кадров проекта:

```yaml
videos:
  - url: 'https://kinescope.io/5R3xLEV8QHLkcs4ev7hKPK'
    cover: 'projects/quchbi-bag/still-1.jpg'
```

Vimeo не отдаёт обложку по предсказуемому адресу, поэтому при сборке к ним уходит один запрос
на видео. Если интернета нет или видео закрыто — сборка не падает, просто останется SOON.

Пока `url` пустой, кнопки Play нет — видна только заглушка. Сам `iframe` грузится **только после
клика** по кнопке Play, поэтому пустая страница остаётся лёгкой.

У проекта может быть два видео подряд — просто добавьте второй элемент в `videos`.
Они встанут друг под другом с отступом 3px, и провайдеры можно мешать: например,
основной ролик с Kinescope, а режиссёрскую версию с Vimeo.

### Страница ABOUT

Всё правится в `src/config/site.ts`, в блоке `about`:

| Поле | Что это | Пропорции |
|---|---|---|
| `showreel` | ссылка на шоурил (Vimeo/YouTube), играет по кругу | 16:9 |
| `photo` | широкое фото | 872:317 |
| `representedBy.logo` | логотип агентства | 204:70 |
| `representedBy.url` | ссылка на сайт агентства | — |
| `representedBy.show` | `false` — скрыть весь блок | — |
| `contacts` | список контактов (label, email, phone) | — |

## 3. Проекты: добавить, удалить, переставить

Один проект — один файл `src/content/projects/<slug>.md`. Имя файла становится адресом:
`quchbi-bag.md` → `/portfolio/quchbi-bag`.

```yaml
---
title: 'QUCHBI BAG'     # короткая подпись на плитке, заглавными
fullTitle: 'Quchbi bag' # полное название: идёт в <title> и в h1
order: 2                # порядок на главной, по возрастанию
thumbnail: ''           # превью 16:9, пусто → обложка ролика, потом SOON
videos:
  - url: ''
    cover: ''
    title: ''
stills:
  - ''
draft: false
---

shot on 8mm film
```

- **Добавить проект** — скопируйте любой файл, поменяйте имя, `title` и `order`.
- **Удалить** — удалите файл.
- **Поменять порядок** — правьте `order`, сортировка по возрастанию.
- **Временно скрыть** — поставьте `draft: true`. Проект пропадёт с главной, и его страница
  не будет собираться.

Под кадрами выводится название проекта, а ниже — текст, написанный под закрывающими `---`.
Это обычный markdown: одна строка вроде `shot on 8mm film` или несколько абзацев описания.
Если ничего не писать, останется только название.

## 4. Имя, роль, меню, соцсети

Всё в `src/config/site.ts`:

- `name` и `role` — то, что стоит в шапке слева;
- `url` — рабочий адрес сайта. **Обязательно поменяйте перед деплоем**: отсюда берутся
  canonical, Open Graph и sitemap. Заодно поправьте адрес в `public/robots.txt`;
- `socials` — иконки в подвале. **Пустой `url` — иконка не выводится**, так что лишние
  удалять не нужно;
- `analytics.umamiWebsiteId` — если пусто, скрипт аналитики не подключается вообще.

## 5. Как сменить шрифт

Сейчас стоит бесплатный Figtree (веса 300, 400, 700), подключённый локально через
`@fontsource/figtree`.

Чтобы поставить другой шрифт:

1. поменяйте семейство в одной переменной `--font-main` в `src/styles/tokens.css`;
2. подключите сам шрифт — либо `npm i @fontsource/<имя>` и импорты в
   `src/layouts/BaseLayout.astro`, либо `<link>` на Adobe Fonts / Google Fonts там же.

Например, для proxima-nova через Adobe Fonts: уберите три импорта `@fontsource/figtree`,
добавьте свой `<link>` в `<head>` и впишите `--font-main: 'proxima-nova', …`.

Базовый размер: `html { font-size: 62.5% }`, то есть **1rem = 10px**. Все размеры в токенах
заданы от этой базы (`1.2rem` = 12px).

## 6. Как вернуть выпадающее подменю

Код подменю уже написан и работает — нужно просто добавить пункту поле `children`
в `site.nav`:

```ts
nav: [
  {
    label: 'WORK',
    href: '/work',
    children: [{ label: 'DIRECTED', href: '/directed' }],
  },
  { label: 'ABOUT', href: '/' },
],
```

Подменю раскрывается по наведению и по фокусу с клавиатуры, и только на ширине **≥ 960px** —
на мобильных оно скрыто.

## 7. Структура проекта

```
src/
  config/site.ts            имя, роль, соцсети, контакты, агентство, меню
  content.config.ts         схема коллекции projects (zod)
  content/projects/*.md     по файлу на проект
  components/
    Header, Footer, SocialIcons
    MediaPlaceholder        белая заглушка SOON
    Media                   картинка или заглушка — решает сам
    ProjectTile             плитка на главной
    VideoEmbed              обложка + Play → iframe
    StillsGrid              сетка кадров (на телефоне 3 в ряд)
    Lightbox                полноэкранный просмотр
    ProjectInfo             название + описание
  layouts/BaseLayout.astro  <head>, мета, Header, Footer
  lib/video.ts              парсер ссылок Vimeo/YouTube (+ тесты рядом)
  pages/
    index.astro             ABOUT (главная)
    portfolio/[slug].astro  страница проекта
    work.astro              WORK
    404.astro
public/
  media/                    сюда можно класть файлы без обработки
  og-default.jpg            превью ссылки в соцсетях (кадр About our love), генерируется `npm run og`
  favicon.svg
  robots.txt
```

Лайтбокс написан с нуля на ванильном TypeScript и CSS: ни jQuery, ни slick,
ни lightGallery в проекте нет.

## 9. Деплой

Сборка статическая, отдавать нужно папку `dist`.

**Vercel.** Импортируйте репозиторий, Vercel определит Astro сам.
Build command `npm run build`, output directory `dist`.

**Netlify.** Build command `npm run build`, publish directory `dist`.

Перед первым деплоем поменяйте `url` в `src/config/site.ts` и адрес sitemap
в `public/robots.txt` на свой домен.
